# 内容生产与组织规范

本文件是项目内部要求，不作为站点页面发布。它是定位、元信息、编辑和评审的依据。

## 目标与边界

站名为“记点儿信息”，项目与域名保留 notes。首页主句为“理解事物如何运转。”

围绕具体问题，整理概念、模型、机制与证据，积累有依据、可修正的认识，服务于生活、成长、企业经营、共同实践及人与 AI 的协作。近期重点为系统工程、组织能力、企业经营与人类活动。经济、科学、技术等领域保持开放；政治议题不纳入选题。

万维钢的得到课程、艾森 Essen 的 YouTube 内容是重要启发来源。只在确有依据时作为佐证，区分作者观点、研究结果、本文推断与假设案例。实际读取全文、字幕、简介或仅标题的范围必须如实判断；不能以看过标题冒充读过论证。必要时核查原始论文、标准或行业资料。

## 内部 DIKW 原则

- 数据(Data)：保留来源、时间、口径和语境；外部材料是输入，不是对本站判断的自动背书。
- 信息(Information)：在清楚的语境中组织材料，定义概念、层次与关系，形成完整且可传播的解释或分析。
- 知识(Knowledge)：经学习、理解或实践形成可应用的认识。本站以实践证据、适用条件与可复用方法支持后续积累；引用他人的知识不等于团队已完成验证。
- 智慧(Wisdom)：在具体目标、约束、价值和不确定性下作出判断，保留取舍理由并接受结果反馈。

它们用于组织工作与追溯关系，不能当成自动升级流程、内容等级或四个强制栏目。对外不展示 DIKW 名词、金字塔或工作定义。

## 元信息

元信息描述文章身份、时间、范围、领域与来源；正文负责解释主题。各项只维护一个来源，模板统一呈现，避免重复标题、来源说明与日期。

| 字段 | 含义与要求 |
|---|---|
| `title` | 当前文章标题，清楚说明研究对象或问题；正文从二级标题开始 |
| `date` | 本站首次发布日期，决定年月归档；后续更新不改变它 |
| `updated` | 实质更新的日期；同一天的更新不在页首重复显示日期 |
| `description` | 对问题与解释范围的简洁概括，不替代全文，不写情绪性推荐 |
| `tags` | 至多两个规范领域关键词，可为空；名称登记在 `src/lib/domains.ts` |
| `source` | 一项主要来源的标题、原作者、载体、日期与原始链接；其他来源在正文就近引用并列入参考资料 |
| `asOf` | 现状或趋势分析使用的资料截止日期；概念解读可省略 |
| `revision` | 本次实质更新说明，与 `updated` 对应；完整修订历史由 Git 保存 |
| `cover` 等 | 与文章内容相关的插画、替代文本与来源说明；封面不承担事实证明 |

本站整理者与来源原作者分别归属。不能把原文发布日期用作本站发布日期，也不能把当前日期写成未经核查的资料截止日期。文章 URL 在发布后保持稳定。

## 解释与分析

以完整问题及论证为阅读单位，按主题自身的依赖顺序展开。整体定义、组成定义、组成内部解析、相互关系和应用条件需要逐层递进。清单、表格、图示只有在帮助理解时使用。不要强迫所有文章套同一章节模板，也不要将上下位概念平铺。

机制解释明确假设和适用边界；现状分析交代时间范围与指标口径；趋势研判说明驱动因素、假设、可能路径与观察信号；个人判断说明依据、推理、替代解释和可能促使修正的证据。模型、经验性规律与严格定律的含义应准确区分。

术语首次定义使用“中文(English)”，后文用中文简称。解释性译名标明性质。专业性来自定义、证据和逻辑，不来自术语堆砌。使用直接、准确的陈述，不写杂文、虚构情绪或未经授权的第一人称经历。

案例标明是来源案例、外部事实、假设示例还是实际实践。来源解读保留原作者的层次和主要论证；延伸内容单独说明性质。不能把相关性改写成因果，把个案改写成普遍结论。

## 关联与阅读

领域关键词表示内容对象，不能使用“阅读笔记”“工作方法”“随想”等内容形式或宽泛修辞。新增关键词先给出规范中文、英文和范围说明，优先复用已登记名称。领域、模型、案例与原始来源通过正文链接、系列文章或后续实践关联，不堆成一组同层标签。

完整文章提供层级目录、可读表格、必要关系图、来源、修订记录与更正入口。目录只呈现主要章节。内容量足够后再增加专题，不创建空栏目。

保留舒适长文排版和少量蓝天、草坪点缀。每篇封面按内容采用细线条、少量淡彩、大量留白的简笔画；目录小图、正文大图。正文图示承担解释任务。

## 发布检查

核对正文是否完整、术语层次是否正确、引用与推断是否分开、图表是否可读、元信息是否一致。构建验证日期和领域词；检查目录锚点、内部链接、RSS、SEO 与图片。检查移动端和明暗主题。评审提出问题，主要执行者负责判断与修正。已获发布授权时，验证通过后发布并核对实际部署结果。
